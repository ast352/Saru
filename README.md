# Saru

Интернет-магазин рубашек: витрина, аккаунты покупателей, корзина, заказы и закрытая зона модератора.

## Локальный запуск

Нужны Node.js 22+, pnpm и запущенный Docker Desktop.

```bash
pnpm install
pnpm db:up
pnpm dev
```

Сайт откроется на `http://localhost:5173`. PostgreSQL сохраняет данные в Docker volume.

Локальный модератор:

- почта: `moderator@saru.ru`
- пароль: `SaruDemo2026!`

Пароль предназначен только для разработки. В production обязательно задайте `MODERATOR_PASSWORD`.

## Production

1. Скопируйте `.env.example` в `.env`.
2. Задайте сложные `POSTGRES_PASSWORD` и `MODERATOR_PASSWORD`, публичный `PUBLIC_URL` и SMTP-параметры.
3. Запустите:

```bash
docker compose up -d --build
```

Приложение будет доступно на порту `8787`. Перед публикацией поставьте перед ним HTTPS reverse proxy (Caddy, Traefik или nginx) и настройте резервные копии volume `saru_postgres` и `saru_uploads`.

## Что реализовано

- регистрация, вход, серверные сессии и восстановление пароля;
- одноразовое подтверждение почты со ссылкой на 24 часа;
- профиль с изменением имени и пароля, адресной книгой и безопасным удалением;
- PostgreSQL-схема с товарами, фотографиями, размерами и остатками;
- корзина с проверкой остатков;
- оформление заказа и автоматическое списание остатков;
- история заказов покупателя;
- создание, редактирование, публикация и удаление товаров;
- загрузка JPG, PNG и WebP до 8 МБ;
- управление статусами заказов модератором;
- Docker-сборка frontend и backend.

Если SMTP не настроен, ссылки восстановления и подтверждения выводятся в консоль API и возвращаются интерфейсу только в локальном режиме. В `NODE_ENV=production` токены никогда не попадают в ответ API.
